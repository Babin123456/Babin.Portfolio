## ✨ Key Portfolio Features

- 🖥️ **Interactive Hacker Terminal** — Built-in terminal emulator supporting commands (`whoami`, `skills`, `education`, `achievements`, `highlights`, `focus`, `hobbies`, `contact`, `clear`, `help`).
- 🔬 **Research & Benchmark Hub** — Dedicated Springer publication overview with interactive season performance tabs (Winter, Monsoon, Summer) and copyable BibTeX citation.
- 🏆 **Achievement Hub** — 430+ certificates, awards, and badges across 59 categories with filter pills, lightbox viewer, and direct PDF downloads.
- 🎨 **Visual Design & Aesthetics** — Strict dual-accent theme (Royal Blue `#1D4ED8` and Mint Green `#89D3BD`), warm parchment light mode (`#FBF7F0`), glassmorphic cards, and 3D flip text.
- 📱 **Mobile-First & Fully Responsive** — Centered layouts on mobile viewports, responsive season tabs, and circular micro-interaction touch targets.
- 📩 **Serverless Contact Form** — Secure contact handling via a decoupled Vercel Serverless Function powered by Nodemailer and Zod validation.
- 🌓 **Next-Themes Theme Engine** — Instant dark and light mode switching with zero flash of unstyled content (FOUC).

## 🚀 Getting Started Locally

### Prerequisites

- **Node.js** (v18.0.0 or higher recommended)
- **npm** or **yarn** / **pnpm**

### Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/Babin123456/Babin.Portfolio.git
   cd Babin.Portfolio
   ```

2. **Install dependencies:**

   ```bash
   npm install
   ```

3. **Start the development server:**

   ```bash
   npm run dev
   ```

   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build for production:**

   ```bash
   npm run build
   ```

5. **Preview the production bundle:**

   ```bash
   npm run preview
   ```
